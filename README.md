
# English Janala – Let's Learn Vocabularies

Expand your vocabulary with quick, clear definitions and smart practice tools built to help you learn faster.  
Your go-to hub for discovering new words, improving language skills, and building confident communication.  
A simple, powerful way to master new words—learn, review, and grow your vocabulary every day.

## Live link
https://english-janala-here.vercel.app/  

## Tech Stack

**Client:** JavaScript, TailwindCSS
**Npm packages:** DaisyUi


## Features

- Search vocabulary by words
- Dynamic Lessons
- Cross platform
